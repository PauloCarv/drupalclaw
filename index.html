What is DrupalClaw?

DrupalClaw is a self-hosted, agent-first workspace built on PiClaw. It packages an AI coding agent with a complete Drupal development stack into a single Docker container.

Talk to the agent in natural language. It creates projects, manages Docker stacks, runs Drush, scaffolds modules, analyzes code, fixes errors, imports databases — all through a unified chat interface with a visual Dev Panel.

PHP 8.3 Composer 2 Drush Docker-in-Docker MariaDB nginx + PHP-FPM PHPStan PHPCS/PHPCBF SQLite
Paulo: create a new drupal project and start the stack

DrupalClaw: Running drupal-init...
$ composer create-project drupal/recommended-project drupal

Running drupal-serve...
$ docker compose up -d (nginx + php-fpm + mariadb)
✓ Stack running on http://localhost:8080

Paulo: install admin_toolbar and rebuild cache
$ composer require drupal/admin_toolbar
$ drush en admin_toolbar -y && drush cr

Quick Start

Up and running in 3 commands

Terminal
# Clone the repository
git clone https://github.com/PauloCarv/drupalclaw.git

# Enter the directory
cd drupalclaw

# Start DrupalClaw + MariaDB
docker compose up -d
Access
# Open your browser
http://localhost:8083

# Click "Init" in the Dev Panel to create a Drupal project
# Click "Start Stack" to launch nginx + PHP-FPM + MariaDB
# Start talking to the agent!
Standalone (without external DB)
# Run standalone with SQLite
docker run -d --name drupalclaw \
  -p 8083:8080 \
  -v "$(pwd)/workspace:/workspace" \
  ghcr.io/paulocarv/drupalclaw:latest
